# ⚙️ Shinobi Backend — Proyecto Naruto DB

**Autor:** Jossue Uchiha  
**Rol:** Analista de Sistemas  
**Tecnologías:** Spring Boot, PostgreSQL (Neon), Maven, Java 17  
**Arquitectura:** Hexagonal (Ports & Adapters con capas DTO, Repository, Service y Controller)  
**Tema:** Universo de Naruto — Sistema de Gestión Shinobi  

---

## 🧠 Descripción General

El **Shinobi Backend** es un proyecto backend desarrollado con **Spring Boot**, diseñado bajo una **arquitectura hexagonal** (*Ports & Adapters*) inspirada en los principios del **Domain-Driven Design (DDD)**.  

Su objetivo es ofrecer una **API RESTful** modular, mantenible y escalable para gestionar la base de datos **PostgreSQL (Neon)** que contiene información del mundo ninja: **Aldeas, Clanes, Personajes, Jutsus y Misiones**.

---

## 🎯 Objetivos del Proyecto

1. Implementar un backend profesional con **Spring Boot + PostgreSQL (Neon)**.  
2. Aplicar **arquitectura hexagonal** para desacoplar la lógica de dominio del framework y la base de datos.  
3. Exponer **endpoints RESTful** que gestionen entidades del universo shinobi.  
4. Usar **DTOs, Services, Repositories y Controllers** para mantener la separación de responsabilidades.  
5. Demostrar un diseño **limpio, empresarial y extensible** para futuras integraciones (frontend o microservicios).
