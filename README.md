# 🌀 Shinobi Front — Interfaz Visual del Mundo Ninja

**Autor:** Jossue Uchiha  
**Rol:** Analista de Sistemas  
**Tecnologías:** React, Vite, TailwindCSS, Axios  
**Integración:** API REST (Spring Boot + PostgreSQL Neon)  
**Arquitectura:** Componentes modulares con Hooks y servicios REST  
**Tema:** Universo de Naruto — Panel de gestión y exploración Shinobi  

---

## 🧠 Descripción General

El **Shinobi Front** es la interfaz visual del proyecto **Naruto DB**, un sistema que permite **gestionar y visualizar información del mundo ninja** mediante una experiencia moderna y atractiva.  

Desarrollado con **React + Vite**, el frontend consume la API REST del **Shinobi Backend** (Spring Boot, arquitectura hexagonal) para mostrar **personajes, clanes, aldeas, jutsus y misiones** en un entorno temático inspirado en la estética shinobi.  

---

## 🎯 Objetivos del Proyecto

1. Crear una **interfaz moderna, responsiva y temática** del universo Naruto.  
2. Integrar la API REST del **Shinobi Backend** usando **Axios**.  
3. Aplicar **componentización** y buenas prácticas en React.  
4. Mostrar habilidades en **UI/UX**, diseño, consumo de APIs y arquitectura limpia.  
5. Servir como **proyecto visual de portafolio profesional**.
