# 🌀 Backend MVC — Jossue Uchiha

## 📘 Descripción
Este proyecto es un **backend desarrollado en Spring Boot MVC** que forma parte de un sistema de gestión inspirado en el universo de **Naruto**.  
El objetivo es aplicar principios de **arquitectura limpia y modularidad**, conectando una base de datos PostgreSQL y desplegándose fácilmente con Docker.

---

## ⚙️ Tecnologías principales

| Componente | Tecnología |
|-------------|-------------|
| Lenguaje | Java 17 |
| Framework | Spring Boot (MVC) |
| Base de datos | PostgreSQL |
| ORM | Spring Data JPA |
| Build | Maven |
| Contenedor | Docker |
